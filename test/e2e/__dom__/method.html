这份数据是什么

八层数据：免费额度、比价、订阅、中转站、AI 活动、工具箱、评测、情报。单位统一 USD / 1M tokens；人民币按 6.6882 折算（open.er-api.com，Fri, 23 Oct 2026，站点每 8 小时自动刷新一次）。

  • 聚合层（462 条）：OpenRouter 实时目录，含缓存读写价。
  • 官方直连层（12 条 / 5 家）：官方定价页人工核实，保留原币数字。
  • 免费层（37 条）：免费额度、免费模型、赠送金，标注门槛与期限。
  • 订阅层（12 档官方 / 18 组区价 / 209 条挂单）：官方档位取 App Store 美国区的公开内购明码，一档一行、带购买链接；区价覆盖 30 个国家/地区；挂单来自公开平台，只作行情，不推荐。
  • 中转层（51 站在册 / 22 站公开价目）：读取 OneAPI/NewAPI 的价目接口。有 billing_expr 的站点按表达式取真实挂牌价，其余按 model_ratio × 分组倍率 换算，再按固定用量画像折成有效成本。
  • 活动层（1690 个开放中 / 23 条已结束 / 1713 条收录）：Devpost 公开接口（按 open / upcoming 分别翻页至收满）+ Devfolio 公开接口 + Luma 公开发现流（AI 关键词过滤）+ 本地 AIOS 活动库。状态一律按截止日期判定，不照抄数据源的 status 字段。
  • 工具箱（21 个）：人工精选的 skill / MCP / CLI，星数、更新时间、许可每天从 GitHub API 校准；归档的会被标出来。
  • 评测层（163 个模型）：Vals Index 的公开分数，每次采集存一份用于对比。
  • 情报层（2259 条 / 63 天有内容 / 跨度 150 天，另有 21 条一手信号）：AIHOT 全量流（7 天窗口，按分类翻页去重）+ 官方精选 + 存档回填，按 URL 归档、只增不删；条目用短键落盘，摘要只留标题里没有的信息。页面先给密度带，再按日/周/月/季/年下钻，默认只摊开最近 12 段。

排序：主流优先，新模型优先

比价表默认不是按价格排，而是按厂商主流度 + 模型发布时间：OpenAI、Anthropic、Google、DeepSeek、通义、Kimi、智谱、MiniMax、xAI、Mistral、Meta 等排前，同厂商内新发布在前；点任意表头可换成价格排序。

有效成本怎么算

cost_per_1M = (1 − s) · [(1 − h) · input + h · cache_read] + s · output h = 缓存命中率 s = 输出 token 占比 cache_read 缺失时按 h = 0 处理，并标 "—"，不假装有缓存优惠

默认 h=70%、s=20%；滑块就是这两个变量。

中转站口径

OneAPI / NewAPI 有两套并存的价目写法，表达式优先：

① billing_expr（真实挂牌价） tier("base", p * 2 + c * 10 + cr * 0.1 + cc * 2.5) p=输入 c=输出 cr=缓存读 cc=缓存写，单位就是 $ / 1M ② model_ratio 倍率（老式） 输入 = model_ratio × 分组倍率 × $2 / 1M 输出 = 上式 × completion_ratio 缓存读 = 上式 × cache_ratio 有效成本 = (1−s)·[(1−h)·输入 + h·缓存读] + s·输出

为什么必须表达式优先：同时给出两种写法的站点里，model_ratio 是废弃占位值——例如某站 model_ratio=37.5 算出 $75，而其 billing_expr 写着 p*2+c*10，真实价是 $2 / $10。只认倍率会把一批正常站点误标成「异常」。

分组倍率（group_ratio）才是中转站的定价核心，跨站差 20–220 倍。页面上的价格取代表分组（default，或组名里声明倍率最接近 1 的公开组），用于横向比较；另单列最低可达价并标出组名，因为那通常要求特定分组权限（会员、Claude Code 专属等）。

有效成本按固定画像折算：h=70% 缓存命中、s=30% 输出占比（agent 编程的典型构成）。输入价常常各家相同，差价主要来自输出倍率与缓存折扣，所以排序用有效成本。

model_price > 0 或表达式 fixed(...) 的按次计价不参与每百万 token 比较；与同口径官方价差 2.5 倍以上（便宜模型放宽到 8 倍，避免小模型被绝对差价误判）才标「口径?」。

订阅与第三方挂单

官方订阅只收 App Store 公开内购页能直接读到的月费，按产品分档、一档一行。第三方挂单价是公开挂单页的当日快照（来源 aibijia.org），只用来判断行情区间：质保通常 1–3 小时，成品号与镜像站的稳定性差别很大，站点不做推荐、不保证可用。

活动与评测口径

活动只收公开可报名的：Devpost 的 open 状态黑客松、Luma 公开发现流里含 AI/LLM/Agent 关键词的场次，按截止日期排。类型（黑客松 / 会议 / Meetup / 工作坊 / 评选）和地区都由标题、主题与场地推断，可交叉筛选；本地 AIOS 项目的活动库全部已结束，单独归档，只作来源对照，不混进「开放中」。

评测层直接读各家公布的公开数据，共 9 个源、12 个榜：LMArena 走它在 HuggingFace 公开的榜单数据集（24 个榜，含中文、编程、Agent、多模态，带 95% 置信区间与票数）；SWE-bench、Aider、Terminal-Bench、τ-bench 取官方榜；ARC-AGI、SimpleBench、Vals、Artificial Analysis 取各自公布的榜单。

口径：各榜量纲不同（Elo / 百分数 / 0–1 比率 / 指数分），采集时按源各自的口径统一成百分数或保留指数，绝不全局乘 100；对照表并排时用的是榜内名次换算的相对位置，不是把分数直接相加。同一模型的多个推理档位（High / Max / xHigh）合并成一条，保留最强档。同一份数据集里混着几代快照时只取最新一批。超过 6 个月没更新的榜会标出「N 个月前」——分数能看，但不代表当前能力。

不采的：Open LLM Leaderboard v2（2025-03 起停止打分）、HarmBench（站上无榜）、C-Eval（证书过期）、CMMLU（2024-12 停更）、SuperCLUE（只有 PDF 报告）、MMLU-Pro 与 GPQA（只有数据集，没有官方榜）。这类停更榜上页面会误导人，宁可空着。

去重规则

  1. R1 聚合层以 OpenRouter model id 为唯一键。
  2. R2 官方直连层以 厂商 + 模型 为唯一键，冲突保留高置信。
  3. R3 两层不合并：渠道是指纹的一部分，只通过 family 做「同族最低」提示。
  4. R4 免费层以产品名为唯一键，多入口合并进 entries。
  5. R5 情报以 URL 为唯一键；同 URL 撞车时保留更早的日期与更长的摘要，永不被新抓到的短版覆盖。中转站以域名唯一。

已知偏差

  • 聚合层标价可能与厂商直连价不同步；两个渠道两个价是正常的，站点不替你选边。
  • Batch / 分时 / 优先档是独立 SKU，各自成行，不折叠成「该模型最低价」。
  • 中转站价目是接口披露价，不等于你充值后的实际单价；未公开价目的站点只登记不猜价。
  • 免费额度随时会变，卡片上的日期是核实日期，链接指向官方页。
