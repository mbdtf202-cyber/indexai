# curated/ —— 人工维护的数据

这里的文件是**手写并核校过**的数据，不是采集产出。改它们不需要读代码。

| 文件 | 内容 | 条数 |
|---|---|---|
| `milestones.json` | 超级大事件（带核验状态） | 44 |
| `offers.json` | 免费额度 | 37 |
| `official-prices.json` | 官方价 | 12 |
| `relays.json` | 中转站在册名单 | 51 |
| `signals.json` | 一手价格信号 | 21 |
| `toolkit.json` | 精进工具箱 | 21 |

## 编辑约定

1. **每条都要能追溯**：带 `source` / `src` / `sources` 字段，指向官方页面。
   没有出处的条目等于一句断言，不要加。
2. **数字用原始精度**：官方写 `$0.1408` 就写 `0.1408`，不要四舍五入成 `0.14`
   ——四舍五入会在比价里变成真实的 0.3% 误差。
3. **缺值写 `null`，不要写 0**：0 是一个价格，`null` 才是「没有这个数」。
4. **改完跑一次 `npm run verify`**：golden 会逐字节比对，改错会立刻红。

## 为什么要外置

这些数据以前是 `collect.mjs` 里的数组字面量，两千行里夹着十几个价格。
改一条价格要在大文件里定位、diff 里看不出改了哪个数字、也没法让别人只改数据。
搬出来之后，改数据只动这里，改逻辑只动代码（T3.1b）。
